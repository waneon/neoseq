# AI Agent Instructions

## Coding Guidelines
- Prefer modern approaches and established best practices.
- Favor a minimal architecture and implementation that meets the requirements.

## Documents

### Architecture Documentation
- Serve as the source of truth for the repository's architecture.
- Focus on the repository's architecture while avoiding implementation details.
- Use ARCHITECTURE.md to describe repository-wide architecture, and files under architectures/ to describe the architecture of a single focused topic.
- Keep each document concise.
- Write these files in English.

### Design Documentation
- Use DESIGN.md as the source of truth for the repository's design.
- When working on frontend design, always take this document into account and design and implement the UI/UX at a production-quality level.

### README.md / DEVELOPMENT.md
- Agents are responsible for updating and maintaining these files, while avoiding unnecessary expansion, duplication, or excessive detail.
- Write for human readers in clear, human-readable language, and keep only the essential information concise.
